# 🗾 Samurai Plus 4K - M3U Player

## English

### About
**Samurai Plus 4K** is an advanced web-based M3U playlist player featuring a sleek dark red and glossy black theme. It supports 4K video streaming, HLS (HTTP Live Streaming), and provides a modern, user-friendly interface for IPTV and media streaming.

### Features
- 🎥 **4K Video Support** - High-quality video playback
- 📱 **Responsive Design** - Works on all devices
- 🎨 **Dark Red & Glossy Black Theme** - Beautiful, modern interface
- 📺 **M3U/M3U8 Support** - Load playlists from files or URLs
- 🔴 **HLS Streaming** - Support for live streams
- ⌨️ **Keyboard Shortcuts** - Full keyboard control
- 🔄 **Shuffle & Repeat** - Playlist control options
- 🎵 **Volume Control** - Full audio management
- 🖥️ **Fullscreen Mode** - Immersive viewing experience
- ⚙️ **Settings Panel** - Customizable options

### How to Use
1. **Load M3U File**: Click "Choose File" to upload your M3U playlist
2. **Load from URL**: Enter an M3U URL and click "Load URL"
3. **Control Playback**: Use the media controls or keyboard shortcuts
4. **Navigate Playlist**: Click on any item in the playlist to play it

### Keyboard Shortcuts
- `Space`: Play/Pause
- `←` `→`: Seek backward/forward (10 seconds)
- `↑` `↓`: Volume up/down
- `M`: Mute/Unmute
- `F`: Toggle fullscreen
- `N`: Next track
- `P`: Previous track

### Technical Requirements
- Modern web browser with JavaScript enabled
- Support for HTML5 video
- Internet connection for streaming

## العربية

### حول التطبيق
**ساموراي بلس 4K** هو مشغل متقدم لقوائم تشغيل M3U عبر الإنترنت يتميز بتصميم أنيق باللون الأحمر الداكن والأسود اللامع. يدعم تشغيل الفيديو بدقة 4K وبث HLS ويوفر واجهة مستخدم حديثة وسهلة الاستخدام للـ IPTV وبث الوسائط.

### المميزات
- 🎥 **دعم الفيديو بدقة 4K** - تشغيل فيديو عالي الجودة
- 📱 **تصميم متجاوب** - يعمل على جميع الأجهزة
- 🎨 **تصميم أحمر داكن وأسود لامع** - واجهة جميلة وحديثة
- 📺 **دعم M3U/M3U8** - تحميل قوائم التشغيل من الملفات أو الروابط
- 🔴 **بث HLS** - دعم البث المباشر
- ⌨️ **اختصارات لوحة المفاتيح** - تحكم كامل بلوحة المفاتيح
- 🔄 **خلط وتكرار** - خيارات التحكم في قائمة التشغيل
- 🎵 **التحكم في الصوت** - إدارة كاملة للصوت
- 🖥️ **وضع ملء الشاشة** - تجربة مشاهدة غامرة
- ⚙️ **لوحة الإعدادات** - خيارات قابلة للتخصيص

### كيفية الاستخدام
1. **تحميل ملف M3U**: انقر على "اختر ملف" لرفع قائمة التشغيل الخاصة بك
2. **التحميل من رابط**: أدخل رابط M3U وانقر على "تحميل الرابط"
3. **التحكم في التشغيل**: استخدم عناصر التحكم في الوسائط أو اختصارات لوحة المفاتيح
4. **التنقل في قائمة التشغيل**: انقر على أي عنصر في قائمة التشغيل لتشغيله

### اختصارات لوحة المفاتيح
- `مسافة`: تشغيل/إيقاف مؤقت
- `←` `→`: البحث للخلف/للأمام (10 ثوانٍ)
- `↑` `↓`: رفع/خفض الصوت
- `M`: كتم/إلغاء كتم الصوت
- `F`: تبديل ملء الشاشة
- `N`: المسار التالي
- `P`: المسار السابق

### المتطلبات التقنية
- متصفح ويب حديث مع تفعيل JavaScript
- دعم لفيديو HTML5
- اتصال بالإنترنت للبث

### تشغيل التطبيق
1. افتح `index.html` في متصفحك
2. حمّل ملف M3U أو أدخل رابط M3U
3. استمتع بالمشاهدة!

### الملفات المضمنة
- `index.html` - الملف الرئيسي
- `styles.css` - أنماط التصميم
- `script.js` - وظائف التطبيق
- `sample.m3u` - ملف عينة للتجربة
- `manifest.json` - ملف PWA
- `favicon.ico` - أيقونة التطبيق
